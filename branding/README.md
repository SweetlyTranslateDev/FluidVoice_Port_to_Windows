# Branding

| File | Use |
|------|-----|
| `fluidvoice_logo.png` | Source logo (README, Flutter UI asset copy) |
| `app_icon.ico` | Multi-size Windows icon (same bytes as runner `app_icon.ico`) |

The Flutter-bundled copy lives at `flutter_app/assets/branding/fluidvoice_logo.png`.  
The Windows exe / installer / tray icon is `flutter_app/windows/runner/resources/app_icon.ico`.
